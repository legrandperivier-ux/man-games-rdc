# MAN GAMES RDC

Application mobile de jeux pour la RDC, avec une première version fonctionnelle dédiée au quiz congolais.

## Démarrage rapide

Ouvrez simplement le fichier `index.html` dans votre navigateur.

## Fonctionnalités de la version actuelle

- Menu principal
- Accueil avec branding MAN GAMES RDC
- Quiz congolais jouable
- Système de points virtuels
- Tableau des meilleurs joueurs
- Profil du joueur
- Interface adaptée aux écrans de téléphone

## Palette de couleurs

- Bleu
- Rouge
- Jaune
- Blanc

## Prochaine étape

Les autres catégories (football, courses, aventure, traditionnels) seront ajoutées progressivement, sans prétendre qu'elles sont déjà terminées.
